# Tempest Leads

Runnable development scaffold: Vite + React (JavaScript), Tailwind CSS, Express and a MySQL pool. This is not the finished lead-management application.

## Start

Use Node.js 24 and npm. Open a terminal in the extracted tempest-leads folder:

    npm ci
    npm run dev

Open http://localhost:5173. The API listens on http://localhost:5000; Vite proxies /api to it. Click Check API connection. No database is required for the starter page.

## Optional database

Copy server/.env.example to server/.env, then run:

    docker compose up -d

The database is empty. There are no lead tables, migrations or database-dependent API routes yet. Compose credentials are for local development only.

## Commands

- npm run dev:client / npm run dev:server — run separately.
- npm run build — frontend output in client/dist.
- npm run preview — frontend build preview only; no API proxy.
- npm start — run the Express API only.
- npm run lint — lint application and configuration files.
- npm run format — format source, excluding original references.
- npx playwright install chromium — install test browser.
- npm run test:e2e — page and API integration smoke test.

## Structure and scope

client/ contains the Vite React app. server/ contains the Express starter and MySQL pool. shared/, docs/, deploy/ and scripts/ contain explanatory placeholders. tests/ contains a Playwright smoke test. .github/workflows/ci.yml runs lint, build and the smoke test.

reference/ contains copies of your original requirements, handoff and HTML/CSS/JS prototype. They are not executed by React. Their presence does not mean their features are implemented.

Authentication, permissions, lead workflows, database schema and production deployment remain to be implemented. node_modules and generated builds are excluded from the ZIP. package-lock.json is generated by npm.
